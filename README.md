## 硬件与跑分：CPU 不虚，磁盘是短板

东京 Pro 跑在 AS3 平台，AMD EPYC 7003 系列，不同批次出现过 EPYC 7443P、EPYC 7402P。

一份公开深度实测给出的数据：Geekbench 5 单核 1254、多核 1238（1 核实例的正常表现），SysBench 单线程 4083 分；fio 混合读写 4K 约 74.8MB/s、64K 约 1.24GB/s、1M 约 2.08GB/s，4K 随机接进万级 IOPS。

另一份实测的意见相反，认为磁盘 IO 偏差，判断是仍在使用较老的存储集群，建议官方升级。

两边的数据都指向同一件事：CPU 单核性能足够应付代理中转、轻量建站和脚本任务，磁盘不要按顶级 NVMe 的预期去要求它。你要跑高强度数据库或者大量小文件读写，先想清楚。

## 三网路由：IPv4 很漂亮，IPv6 是另一个待遇

这部分是品川的卖点，也是它贵的原因。

**IPv4 去程**：电信走 CN2 GIA 直连日本，联通走 AS4837 / AS10099，移动走 CMI。

**IPv4 回程**：三网统一强制走 CN2 GIA，从上海回来。

**IPv6 回程**：走各家运营商自己的骨干，比如电信走 163。也就是说，如果你靠 IPv6 跑业务，拿不到和 IPv4 同等的优化。

实际延迟方面，多个测试帖给出的结论是全国大部分地区在 60ms 上下，上海可以到 31ms。带宽标称 500Mbps，在优质路径上单线程能跑到 540–570Mbps，基本算跑满。

在联通和移动的部分路径上，报告里出现过波动，不是每个节点都同样漂亮。这句话不是黑它——CN2 GIA 的优势本来就在电信方向，联通移动属于"顺带不错"，心里有数就行。

## IP 质量：别为了解锁买这台机器

DMIT 手上的 IP 段很多，具体给到你哪一段要看运气。综合几份第三方测试：日常访问各家 AI 服务基本可以，流媒体解锁参差不齐，风控严格的服务（例如部分 Meta 相关产品）用不了。

还有一个经常被问到的坑：新购机器的 IP 地理位置有时会显示在美国，这是 IP 数据库没更新，等一到两周才会归位。这期间被误判是正常的，不是发错机器。

换 IP 的规则：IP 被墙时每 15 天可以免费更换一次；其他情况付费更换，费用约 5 美元一次。

所以品川的定位是线路机、中转机、落地机，不是解锁机。冲着 Netflix 或风控绕过去的，这台机器大概率让你失望。

## 几个被问得最多的问题

**品川有月付吗？**
没有。目前只有季付 69.90 美元和年付 239.90 美元两个周期。

**500GB 还是 800GB？**
早期批次是 500GB，后来官方升级到 800GB。现在以官网标注为准。

**晚高峰真的稳吗？**
IPv4 回程强制走 CN2 GIA，从上海回国，这是它最不容易崩的一段。联通和移动的部分去程路径曾经出现过波动，不属于电信级别的一视同仁。

**和香港 Pro 比怎么选？**
香港 Pro 回程同样走 CTG / CN2，距离更近、延迟更低，但价格更高。如果延迟是硬指标且预算充足，香港更合适；如果只是要一台优秀的日本优化机，品川是更常见的选择。

**和洛杉矶 Pro 比怎么选？**
洛杉矶 Pro 的门槛低得多，月付 10.9 美元就能进 Premium 网络，年付 36.9 美元还有 WEE。回程同样是三网 CN2 GIA，代价是跨太平洋的绝对延迟更高。预算优先选洛杉矶，延迟优先选品川。
